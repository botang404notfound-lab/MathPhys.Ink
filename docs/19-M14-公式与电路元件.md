## 1. 技术选型：为什么是 WPF-Math，不是 KaTeX/WebView2

| 候选 | 结论 | 理由 |
|---|---|---|
| WPF-Math 2.1.0（NuGet） | ✅ 采用 | 纯托管、内嵌数学字体、`RenderToGeometry` 直接出矢量 `GeometryGroup`；**零浏览器依赖** |
| KaTeX + WebView2 | ❌ | 轻量版不带 `webview2\` 运行时（860 MB），KaTeX 路线在轻量版上必死 |
| ExcaliMath 整体 | ❌ | 必须连同 Excalidraw + React 一起跑 = 白板套白板；Plotly 与 GeoGebra 功能重叠；个人项目、英文界面 |

### S0 勘验结论（写代码前用 spike 工程验证过）

- API 形态（2.x 与 0.x 完全不同）：
  - 解析：`WpfMath.Parsers.WpfTeXFormulaParser.Instance`（单例，静态构造时装内嵌字体）；
  - 环境：`WpfMath.Rendering.WpfTeXEnvironment.Create(TexStyle.Display, 20.0, "Arial")`；
  - 渲染：`formula.RenderToGeometry(env, 20.0)` → `GeometryGroup` —— **几何与笔刷分离**，
    外部 `DrawGeometry(墨色刷, null, 几何)` 即可染色（不需要 `SetForeground`）；
  - 测量：`Geometry.Bounds`，无需另找 Extent API（0.x 的 `formula.Extent` 在 2.x 不存在）。
- 符号覆盖：物理常用全通过（分式/根号/`\vec`/希腊字母/`\int \sum \perp \parallel \overline \%`）。
- **`\mathbb` 不支持；中文（CJK）必然失败** —— Arial 无汉字字形且无法取度量
  （`TexCharacterMappingNotFoundException`）。输入面板里写明这条边界。

## 2. 公式插件（`plugins\formula\formula.dll`）

- `FormulaTool`（**IGfxTool**）：激活弹 LaTeX 输入面板（无模式 Window，Topmost，居中），
  点画布落对象 → 宿主自动切回选择。落成前校验：空串 / 解析失败**不落对象**只提示。
- `FormulaPanelWindow`：文本框 + 实时预览（Viewbox 包 FormulaVisual）+ 20 个快捷符号
  （在光标处插**骨架**如 `\frac{}{}`）+ 回车关面板；面板记住内容支持连续落。
- `FormulaRenderer`（Kind = `latexFormula`，LaTeX 存 `Texts["latex"]`）：
  - 尺寸规则：**高固定** `NominalWorldHeight = 44` 世界点（≈1.55 cm），宽按排版纵横比；
  - 仿射变换 `p_local = (p_tex − bounds中心) × k` 把几何挪到"以 (0,0) 为中心"；
  - ★ 先设 `Transform` 再 `Freeze`（工程铁律）；解析结果按 latex 字符串缓存（上限 128 条）；
  - 无效 LaTeX 退化为虚线占位框（72×30）—— 占位框要够大，否则点不中删不掉。
- 颜色 = 创建时墨色（`obj.Color`），矢量填充，缩放不失真。

## 3. 电路元件插件（`plugins\circuitkit\circuitkit.dll`）

- `CircuitTool`（**刻意不实现 IGfxTool**，与题号标记同款决策）：搭电路要**连续放十几个元件**，
  落一个就弹回选择工具节奏就断了。调色板无模式窗口，点选元件 → 点画布落下。
- **导线 = 拖动手势**：按下记起点、移动画橡皮筋（`AddPreview`，宿主抬笔自动清）、
  抬起落线。落成参数：中心 = 中点、`RotationDegrees = Math.Atan2(dy, dx)`
  （y 向下坐标系正角 = 屏幕顺时针，与宿主 `Matrix.Rotate` 同向，**无需换号**）、
  `Numbers["halfLen"]` = 半长。短于 12 世界点视为手抖不落。
- `CircuitRenderer`（Kind = `circuitSymbol`，元件名存 `Texts["symbol"]`）：
  - 17 种元件几何**直接按世界点定义**（不走"数学单位 ÷ unitWorld"——不绑坐标系，
    没有那个放大问题）；`Geometry.Parse` 缩写语法 + 静态冻结，调色板图标与画布同源；
  - 线宽除 Scale（箭头插件的老坑）；电表内字母（A/V/G/M）用 `FormattedText` 画在
    本地坐标 —— 属于元件本体，**随对象缩放是正确行为**（区别于屏幕恒定的读数）；
  - 未知元件键 → 虚线占位框，不炸。
- 元件清单：电池/电池组/开关(断开/闭合)/电流表/电压表/灵敏电流计/小灯泡/电阻/
  滑动变阻器/电容/电感/二极管/电动机/通电螺线管/接地/交流电源（17 种）+ 导线。

## 6. 过程坑

1. **harness 源级断言撞注释**：CircuitTool 的 remarks 里写了"刻意不实现 IGfxTool"，
   裸 `Contains("IGfxTool")` 断言假 FAIL —— 必须先 `StripComments`（M13 有先例，又踩一次）。
2. **heredoc 全角字符转码损坏**：bash heredoc 里带中文锚点的 Python 补丁偶发不匹配
   （`·`/`（` 等字符进入时被转码）。对策：锚点用 `\u` 转义构造、长中文块走
   Write 工具写模板文件再由 Python 读入替换。
3. `TexFormulaParser` 在 2.x 需要构造参数 → 用 `WpfTeXFormulaParser.Instance`；
   `RenderToBitmap` 第二参是 `TexEnvironment` 不是 scale —— 全部以源码（GitHub API）
   为准核对签名，spike 先行。

## 7. 已知边界（下一版候选）

- 公式 / 元件尚无参数面板（改内容 = 删了重落）；`IGfxParameterProvider` 已预留。
- 公式不支持中文（上游无 CJK 字形）；需要中文标注用墨迹/题号。
- 导线暂无 45° 吸附与端点吸附（`ISnapTargetProvider` 已有基建，可后补）。
