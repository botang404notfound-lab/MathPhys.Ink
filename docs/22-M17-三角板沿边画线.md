# M17 — 三角板沿边画线

> 日期：2026-09-24 ｜ 回归：PdfSmokeTest 全量（M17 新增 7 条断言，见 §5）｜ 双包：完整版 + 轻量版

## 1. 缘起与需求

老师沿三角板画直线的真实动作是：**把板摆在卷面上，笔贴着边走**。M14/M15 落成的三角板是
「创建型」的（落成图形对象，可拖转可存档），但只能"比着看"，不能"沿着画"。本里程碑补上这一刀：

1. 落笔靠近三角板的**任何一条边**（容差 20 屏幕像素，随缩放换算）→ 激活该边；
2. 移动时实时预览**起点到当前点在边所在直线上的投影**（t 不夹 `[0,1]`，可画出比板更长的延长线）；
3. 投影点靠近边端点时**吸附到顶点**（容差 24 世界单位，与三角板顶点吸附同一条）；
4. 抬笔落成**普通墨迹**（`CommitStrokes`）：撤销、橡皮、`.tbink` 持久化全部白得；
5. 落笔在**三角形内部** → 拖动整块板（不切工具）；落笔在板外 → 忽略 + 状态栏提示；
6. 板的**旋转**交给「选择」工具（已有能力）——工具内再做旋转把手会跟「画线/拖板」抢手势。

分工：先用「三角板·45°/60°」（创建型，快捷键 7/8）摆板，再用「沿边画线」（快捷键 9）用板。

## 2. 设计决策

| 决策 | 取舍 |
| --- | --- |
| 板实体复用 `triangle` 图形对象 | 板已是持久 Gfx 对象（刻度渲染、选择拖转、存档全有），零重复建设；宿主/画布层/墨迹层**零改动** |
| 新增独立工具 `triangle-trace` | 不改两把创建型工具的"落笔即创建"语义；职责一刀切：摆板一把、用板一把 |
| 几何抽 `EdgeSnapHelper`（Abstractions） | 边检测/投影/顶点吸附/点在三角形内 = 纯函数静态类，直尺、圆规等任何带直边模板工具共用 |
| 位姿换算插件内自算 | `Matrix` 前乘 Rotate→Scale→Translate = 平移·缩放·旋转，与宿主给视觉施加的变换同一套数学（M15 引脚换算已验证）；插件不拿宿主 RenderTransform |
| 多板只认 Z 序最上层 | 规则一句话说得清；想换板就挪开或删掉上层那块 |
| 不实现 `IGfxTool` | 本工具落的是墨迹不是对象，画完一条还要画下一条；自动弹回「选择」只会打断节奏 |

## 4. 关键实现细节与坑

1. **投影与距离是两套 t**：画线终点用 `ProjectOntoLine`（t 不夹，延长线是立身之本）；
   距离判定用 `DistanceToSegment`（夹 t，端点外按端点算）。混用任何一半都会画不出线或吸错位。
2. **顶点吸附作用于投影点**：先投影、再对边的两端吸附；起点吸附对**三个顶点**（落笔贴直角顶点时
   最近边可能是任一条，直接吸顶点才准）。
3. **容差除以 `Scale`**：`EdgeTolerancePixels(20) / SafeScale(context)` —— 屏幕像素定手感、
   世界单位做几何，不同缩放下手感一致。`SafeScale` 对 0/NaN/∞ 退 1（照直尺文字反缩放同一套）。
4. **拖板撤销步只记一次**：按下记录 `_downCenter`，第一次位移超过 1 世界单位才 `BeginStep`；
   之后的每帧 `UpdatePose` 归入同一撤销单元。按住不动抬笔 = 无空白历史。
   （第一版用 `world - (center + grabOffset)` 判位移——恒等于 0，永远记不上；改为
   `center - _downCenter` 才对。这类"自证恒真/恒假"的表达式要警惕。）
5. **拖板三值一起给**：`UpdatePose(id, center, 按下时的旋转, 按下时的缩放)` —— 旋转/缩放在
   按下时锁定，拖动只改位置，避免"只转了一半"的中间态。
6. **落墨两点 `FitToCurve=false` + `IgnorePressure=true`**：沿边画出来必须严格共线，绝不能被拟合成曲线（照直尺）。
7. **harness 的 IGfxObjectHost 要走真通道**：`GfxObjectStore` 不实现 `IGfxObjectHost`，必须包
   `HostGfxObjectHost(store, GfxHistory, BoardHistory)`（撤销历史的 `BeginStep` 在里面）——
   直接把 store 塞给 `GfxOverride` 编译都过不了；M15 之所以能直接用 store，是因为吸附纯函数只吃 `Objects`。

## 5. 验证（RunM17Checks 7 条）

1. `EdgeSnapHelper` 距离夹 t（段内垂足 / 端点外）+ 投影不夹 t（t=1.5、t=−0.5 延长线）；
2. 最近边选中判定 + 顶点吸附容差内外 + 三角形内判定（内部/外部/边界/双向顶点序）；
3. 真状态机·沿边画线：Down 贴边 → Move 滑出板外 → 预览终点在延长线上 → Up 落墨两点严格共线，板不增不减；
4. 真状态机·顶点吸附：落笔距直角顶点 ≈2.8 → 落墨从 (100,100) 出发；
5. 真状态机·板内拖动：(132,68) 离三边均 >20（不误触画线）→ 板心跟手、不落墨；
6. 板外落笔 / 画布无板 / 无图形层：三者都明确提示、不崩、不落墨；
7. 源级护栏：容差除缩放、不实现 IGfxTool、插件已注册。

## 6. 手工验证步骤（一体机）

1. 快捷键 7 放一块 45° 板，用「选择」旋转到任意角；
2. 切「沿边画线」（快捷键 9），笔尖靠近任一条边（约 2 mm 内）按下拖动 → 预览严格贴边、
   滑出板外线继续延长 → 抬笔落直线，Ctrl+Z 一步撤销；
3. 起点按在角顶点附近 → 线精确从顶点出发；
4. 按在板内拖动 → 板整体跟手；抬笔后板不动、卷面无墨；
5. 按在板外 → 状态栏提示，卷面无任何变化；
6. 缩放到 200% / 50% 重复 2，边吸附手感应一致；
7. 切橡皮擦线、保存工程重开 → 线是普通墨迹，板还在。

## 7. 遗留与后续

- 圆规工具（半径画弧）可直接复用 `EdgeSnapHelper` + 新增圆弧投影；
- 直尺如需"实体尺沿边画线"可平滑迁移到同一套（现两点约束式不动）；
- 60° 板斜边刻度方向与 45° 板一致，沿斜边画线无需区分板型（几何对两板统一）。
