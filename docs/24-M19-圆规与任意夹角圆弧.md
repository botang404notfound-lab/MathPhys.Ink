## 4. 圆弧数学方案（只用 `Point` / `Vector` / `Math.Atan2`）

**角度约定**（整套代码唯一的约定，写反的表现是弧翻到圆的下半边）：

- 0° = 正右、90° = 正上；世界 y 轴向下 ⇒ `LocalDirection(θ) = (cos θ, −sin θ)`。
- `ScreenAngle(center, target) = Normalize360(−Atan2(dy, dx) · 180 / π)`。
- `Sweep(start, end) = Normalize360(end − start)` = **沿屏幕逆时针**从起角转到止角的角度；
  起止相等时为 0（调用方据此画整圆、显示 360°）。

**圆弧几何**（`GeometryHelper.BuildArcGeometry`，本地坐标原点 = 圆心）：

```
BeginFigure(LocalPoint(R, start), isFilled: false, isClosed: false)
ArcTo(LocalPoint(R, end), new Size(R, R), 0,
      isLargeArc: sweep > 180, sweepDirection: SweepDirection.Counterclockwise,
      isStroked: true, isSmoothJoin: false)
```

- 两个等半径端点之间有两条弧，`isLargeArc` 二选一；`Counterclockwise` 与上面的角度约定互相咬合。
- 起止角相等（含 359.98° / 0.02° 这种跨 0° 环绕）⇒ 退化成 `EllipseGeometry`（整圆）。
- 用 `StreamGeometry` + `Freeze()`（**先设 `Transform` 再 `Freeze`**，项目铁律）；不用任何第三方几何库。

**角度数字**：锚点 = `LocalPoint(1.12R, start + sweep / 2)`，字号 = `0.09R`（属于「图形的一部分」，
随半径等比，不是固定像素），文字 = 扫描角取整 + 度号；起止等角时给 360°；先设 `TranslateTransform` 再 `Freeze`。

**吸附**：`TrySnapAngle` 把角吸到 15° 整数倍（容差 5°）；**没吸上必须交回原值** —— 90.1° 就该是 90.1°，
凭空跳到 90° 会让「任意夹角」这个立身之本失真。

## 5. 交互状态机

| 当前状态 | 指针按下 | 指针移动 | Esc（`TryCancel`） |
| --- | --- | --- | --- |
| 空闲、无对象 | 放针尖（先吸点 / 线）→ 进入放置中 | — | `false` ⇒ 宿主切回上一个工具 |
| **放置中** | 落成对象（`gfx.Add`；整圆只记 `radius`、圆弧记 `radius / start=0 / end=90`） | 预览半径跟手（**只换 `Path.Data`**） | 丢弃半截预览、手柄复位到已有对象上，返回 `true` |
| 空闲、有对象 | 命中控制点 → 进入拖动；没命中 → 放新对象 | — | 同上（`false` 只在「什么都没有」时出现） |
| **拖动中** | — | 只改对象依赖属性（`UpdatePose` / `UpdateNumbers`）+ 重摆手柄 | 按拖动起点快照**原样回滚**，返回 `true` |

要点：

- 四个控制点由工具自己画在预览层、自己命中（圆心 / 笔尖 / 起角 / 终角；圆弧模式笔尖放在弧中分角，
  起止等角时挪回正上方）；手柄尺寸与命中容差都 ÷ 当前缩放。
- 「一次拖动只开一步撤销」：第一次真的动了才 `BeginStep`（标签：`拖动圆规圆心` / `调整圆规半径` /
  `调整圆弧起点角` / `调整圆弧终点角`）。
- **对象才是真相**：`StartPlacing` 会覆写 `_center` / `_radius`，`CancelPlacing` 必须从已落成对象读回来
  （见 docs/06 §24.5，这是个真 bug 的回归护栏）。
- 整个工具生命周期只建一次预览图元（`EnsurePreview` 早退 + `gfx.Add` 全文件只出现 1 处），
  拖动 / 缩放只改依赖属性，**不重建视觉树**。

## 6. 宿主接线（契约只加新接口）

```csharp
public interface ICancellableTool   // 新文件，ITool 成员零新增
{
    bool TryCancel();               // true = 已取消一步、仍留在原地；false = 宿主切回上一工具
}
```

- `CanvasViewportHost`：`SetTool` 记住「激活它之前是谁」（`_toolBeforeCancellable`）；
  `TryCancelActiveTool()` 先问工具，工具说没有可取消状态时才切回上一个工具（没有记录则回笔）。
- `MainWindow`：Esc 分支**排在「退全屏」之前**（否则拖半径时按 Esc 会同时取消预览又退出全屏）。
- 老插件不认识这个接口，用 `is` 判断且必须实例实现 ⇒ 行为一字不变。

## 7. 验证（`RunM19Checks`，32 条）

- **纯几何 8 条**：角度约定四方向 + `LocalPoint(110,90)=(0,−110)`；扫描角 0→90=90°、90→0=270°、
  350→10=20°；起止等角（含跨 0° 环绕）走整圆；半径夹取 + NaN 退回默认；整圆包围盒 220×220 且已 `Freeze`；
  **圆弧逆向**；角度吸附三条边界（含「没吸上必须回原值」）；角度数字锚点 + 文案。
- **圆规状态机 13 条**（真 `HostGfxObjectHost` + 真 store / history）：放针尖 → 预览圈（只换 `Data`）→ 落成
  （r=90、无起止角、撤销一步）→ 两个控制点 → 拖针尖（r 不动）→ 拖笔尖（r 90→200）→ Esc 中途回滚 →
  放置中 Esc 手柄复位 → 复位后仍可拖 → 缩放 2× 手柄边长 8 → **2× 容差 10 抓不住 15 处** →
  **1× 容差 20 抓得住同一点** → 无图形层降级提示。
- **圆弧状态机 6 条**：落成（起止 0° / 90°、四个控制点、`Measure` = 2.5R、文案 90°）→ 拖起点到 60° →
  Esc 回滚 60° → 拖终点到 150°（文案「60° → 150°（90°）」）→ 终点拖回起点角按整圆 + 360° →
  缩放 2× 四个控制点世界边长 8。
- **注册与护栏 5 条**：插件注册 2 个工具 + R / A 各自可查；容差与手柄边长都 ÷ `SafeScale`；
  `Atan2` + `ArcTo` + 逆向 + 只 Update 不重建 + 不实现 `IGfxTool`；渲染器不碰 `RenderTransform`；
  Esc 接线（工具层在前、退全屏在后）。

两条断言的写法本身就是护栏，别退回旧写法：

1. **弧的方向用 `Geometry.StrokeContains`（描边命中）判「点在不在弧上」**，不用「端点相等」也不依赖拍平折线：
   弧画反了照样过两个端点，只有查弧中段（45° / 225°、100° / 300°）才看得出来。
2. **缩放后的容差要成对验**：同一个「离针尖 15 世界单位」的点，2× 下抓不住、1× 下抓得住 ——
   只测一边都可能恒真。
