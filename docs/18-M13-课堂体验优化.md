| # | 真机反馈 | 方案 |

## 2. 实施记录（S1~S5）

### S1 光标隐藏（最小步，契约零变化）
工具自己申报 `Cursor` 是既有模式 ⇒ 只改申报值：内置 3 处 + 插件 8 处 → `Cursors.None`。
保留：HandTool(Hand)、GfxSelectionTool(Arrow)、ArrowDecomposeTool(Hand，手势操作)、GeoGebraTool(null)。
harness M4 笔/橡皮光标断言、M7.4 三条矢量工具形态断言同步更新为 None。

### S2 纸张底色
- **机制**：`_paperBrush` 共享**可变** SolidColorBrush 单实例（不 Freeze）—— RootGrid（页外留白）与每页纸面 Rectangle 都指向它，`SetPaperColor` 改 `brush.Color` 一处全页生效。页内矩形在 WorldHost 内 ⇒ 导出（RTB 渲染 WorldHost）天然所见即所得。
- ★ harness 兼容：M4 断言曾用 `CanvasBackground` 属性临时换黑底定位页面 ⇒ `SetPaperColor` 顺手把 RootGrid 接回共享画刷（自愈）。
- 预设色进 `Palette.Canvas.xaml`（Canvas.* 板语义：进导出、不随主题）；入口 = 工具栏「纸张」按钮 + 4 色圆片 Popup（色圆用 MouseLeftButtonUp，触屏友好）；`UiStateStore` 新键 `paper_color`。
- 只做浅色系：黑纸配黑墨看不清，刻意不做深色。

### S3 悬浮球重构
- 双自由度：`XRatio`/`YRatio`（0~1 clamp），Margin 左上基准铺满宿主（Background=null 不截胡输入）。
- 菜单从内嵌 StackPanel 改 **Popup**（Placement=Left，越界自动翻转）—— 球拖到画布中央也能展开。
- 事件 `YRatioCommitted` → `PositionCommitted(X, Y)`；`UiStateStore` 新键 `ball_x`（与 ball_y 同 "0.000" 不变式格式）。
- 菜单固定 7 项（BuildBallMenu，装配一次不再重建）：pen / eraser / hand / gfx-select / ruler-free / calc.open / toolbar.toggle —— 删除原 RebuildBallMenu 的全量工具+模式+宏枚举。菜单稳定，肌肉记忆才立得住。

### S4 工具栏浮动化（最大改动）
- **容器**：TopChrome 从 `DockPanel.Dock=Top` 迁入画布格（`CanvasOverlayGrid`），画布之上、球之下。窗口顶部不再有任何固定栏。
- **拖动**：新助手 `Views/Controls/FloatingDrag.cs`（静态 Attach：触摸/鼠标双链路捕获，位移>6 DIP 才算拖，位置 clamp 在容器内）——**只有把手条响应拖动**，按钮点击与拖动天然分离；计算器面板复用。
- **状态机大幅简化**——删除整套 M12 S1 临时机制：TopRevealStrip / `_toolbarTempShown` / 4 秒 DispatcherTimer / ShowToolbarTemporarily / HideToolbarTemporarily / OnChromeDismissCheck / IsWithinTopChrome / 窗口两个 Preview 隧道挂接。保留：`_toolbarHidden` + ApplyToolbarState / SetToolbarHidden / ToggleToolbar + F9 + 总线 toolbar.* 三命令。**RunM12Checks 的 S1 源级护栏（三方法零缩放调用）继续通过**。
- **位置持久化**：`toolbar_x`/`toolbar_y`（画布比例 0~1，跨分辨率无漂移）；SizeChanged / Loaded 时按比例重摆（clamp 防小窗口出界）。
- **收起/展开**：收起 = 面板 Collapsed + 球按策略出现；展开（SetToolbarHidden(false)）= 面板落在球位置（clamp）并记忆。面板上有「收起 ▲」按钮，与球菜单/F9 三路同效。

### S5 计算器
- **求值器** `Infrastructure/ArithmeticEvaluator.cs`（~150 行纯函数）：递归下降 `expr → term (('+'|'-') term)*`；`term → unary (('*'|'/') unary)*`；`unary → '√' unary | '-' unary | number`。√ 进文法 ⇒ `√9+1=4`、`√√16=2` 无特判；除零/残缺/非法字符/双小数点一律 false。
  ★ 命名避开 `FunctionPlot.Expr.ExpressionEvaluator`（harness 两个 using 下会 CS0104 撞名）。
- **面板** `Views/Controls/CalculatorPanelView.cs`：纯代码 Border 挂 RootGrid（同 LayerPanelView 惯例）；4 列按键（0 占两格）；边按边出结果（等号只是定稿）；算式不对就地提示不清输入；FloatingDrag 拖标题行，会话内定位不落盘。
- **入口**：总线 `calc.open` + 工具栏按钮 + 球菜单第 6 项。

## 3. harness 新增（RunM13Checks，7 条）

① 11 工具光标 None + 3 工具保留；② 旧三态机制退役 0 残留 + 显隐方法体零缩放（M12 护栏复跑）；③ 球 XRatio/固定菜单/BuildBallMenu；④ XAML 浮动化落地（CanvasOverlayGrid 内含 TopChrome/ToolbarGrip/收起钮、无 Dock 顶置、FloatingDrag.Attach）；⑤ 4 新键往返 + 非法回落；⑥ 求值器 12 例；⑦ 纸张底色共享画刷 + **米黄像素验证**（视口中心均值 RGB=(253,246,227) 精确命中）。

## 4. 途中踩的坑（详见 docs/06 §17）

回旧断言撞新设计 6 FAIL（光标/形态断言按新语义更新、9 处裸色值令牌化）；ExpressionEvaluator 撞名 CS0104；XAML 块迁移要「摘出→改→重缩进→插入→删原块」两步走（只插不删会双份）。

## 5. 留给现场验证的点

- 把手拖动与按钮点击在触屏上零误触；球在四角/中央的菜单弹出方向；
- 纸张色在投影仪上的观感（米黄/淡绿/淡蓝）；
- 收起态下主题/窗口模式按钮随栏隐藏是否可接受（已知取舍，见操作卡「已知的几件小事」）。
