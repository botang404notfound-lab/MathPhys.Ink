## 2. 工具栏账目（M23，**包本体实测**）

| 变体 | 工具 | 瓦片 | 折叠 | 其他 | 可点目标 | 工具栏实测 |
| --- | --- | --- | --- | --- | --- | --- |
| 完整版 | 26 | 17 | 9 | 0 | **61** | **500×699** |
| 轻量版 | 24 | 15 | 9 | 0 | **59** | **500×649** |

- 完整版：M22 基线 23 + 坐标系两折叠成员 +2、subjectkit 瓦片 +1 = 26 = 17 瓦片 + 9 折叠。
- 轻量版：M22 基线 22 − nativesim 的 phys-sim 瓦片 +1（subjectkit）+2（坐标系成员）= 24 = 15 瓦片 + 9 折叠。
- ★ **targets 的坑**：坐标系从单瓦片**升格成族**后，族代表瓦片多出一颗**折叠展开钮**，
  所以 targets = 旧值 + subjectkit + 1（展开钮），**不是** + subjectkit + 2（折叠成员在收拢态不产生可点目标）。预判 62/60 双双差 1，实测 61/59 才是真值。
- ★ **高度按变体不同**：轻量 15 颗瓦片与 M22 相同 ⇒ 高度不变（649）；完整版 17 颗多排一行 ⇒ 649→**699**。720 屏已很满，**实机验证时重点看工具栏有没有顶到屏幕边**。

## 3. 关键设计点

### 3.1 深色默认迁移（S2）

- 「默认」三层不变：组件出厂值 / 应用层兜底 / 用户持久化。M23 只动**出厂默认**；
- 老用户迁移用 `UiStateStore` 一次性键 `paper_color_m23`：条件 = 当前持久化是「白」且未迁移过
  ⇒ 改「黑」并落盘。选过其它色的用户尊重其选择；
- 纸色只在**页外**可见（页内被 PDF 白底位图盖住）——这条 M21 已踩过，操作卡里要写清。

### 3.2 坐标系族（S3）

- 族机制：`ToolCatalog.cs` 里代表 `coordsystem` 挂 `FamilyTitle`，成员用 `VariantOf`
  紧跟代表；成员恒折叠，不单独成瓦片；
- 无网格平面 = 复用平面坐标系渲染器，`GfxDraft` 带 `showGrid=false`；
- 三维 = **静态轴测**（DirX 左下 45°、DirY 右、DirZ 上），不引入旋转交互——
  课堂场景只要「画出三轴 + 刻度 + 字母」，旋转是过度设计；
- 固定尺寸图元照旧除 Scale；「世界长常量」除 `unitWorld`。

### 3.3 学科工具 SubjectKit（S4）

- 新工程、走 collectible ALC 加载，契约零改动（`ITool` + `ITransientTool`）；
- 位图走 M22 S4b 的 `IGfxObjectHost.AddImage` 通道：字节进宿主仓库与 `.twb` images/ 段
  （stored + SHA-256），对象只记 `Texts["imageId"]` 与 `Numbers["w"/"h"]`；
- 目录 `SubjectCatalog.cs` 数据驱动：`resource name / 显示名 / 教学提示`，
  加图三步 = 拷 png 进 Assets、加目录项、发版；
- 图片资产 `EmbeddedResource` 嵌进 dll —— 插件单文件自包含，铺装脚本零特判。

### 3.4 CircuitJS 打不开（S5）——「界面合法的静止」式 bug

四个根因叠加，症状是「点了没反应」，不报错、不空白：

1. iframe 的 load/error 事件没人听 ⇒ 页面 404/崩溃上层不可知；
2. `currentPage` 一旦置位，后续打开同页直接短路返回 ⇒ 第一次失败后**永不重试**；
3. probe 结果缓存终身有效 ⇒ 首次探测失败后永远失败；
4. ready 闸门无超时 ⇒ 卡死时面板永远停在「等待就绪」。

修法对应四条：index.html 加 iframe load/error 监听 + 30s 看门狗；probe 缓存在每次
hello 时清空；`WebPanelController` 加 20s ready 超时（超时按打开失败回滚，回滚纪律不变）。

### 3.5 PhET 全板块（S6）

- 45 个仿真（力学 16 / 波光 8 / 电磁 14 / 热流 3 / 天近 4），官方 metadata 接口与
  sitemap 已 404 ⇒ 清单硬编码在 fetch 脚本里（每个 slug 都真实探测过 URL）；
- 语言回退：self-contained 单文件把语言烧死 ⇒ **选下载文件 = 选语言**，
  zh_CN 优先、缺简体的取 zh_TW（fourier-making-waves）、再 en；
- Cloudflare 拒默认 UA（403）⇒ 必须带浏览器 UA；
- **同源生成**是本轮最重要的工程纪律：`fetch_phet.py` 一份脚本同时产出
  ① `index.html` 路由表（PHET-ROUTES:BEGIN/END 标记区）② `WebSimEntries.generated.cs`，
  并 verify 三者同源（资产目录 / 路由表 / 入口表）；
- 再接第 N 个仿真 = 一条路由 + 一个子包 + 一份 fetch 清单项，控制器/profile/契约零改动。

## 4. 打包链路（S7）

1. 整体 `dotnet build sln -c Release -m:1 -nodeReuse:false`（0/0）；
2. `dotnet publish` 主工程 → `dist/tablet`（Assets/websim 以 Content 跟 publish 走；
   **publish 前先挪走旧暂存**，否则残留文件混进新包）；
3. `tools/_stage_plugins.py` 铺 12 个插件（新鲜度闸门：dll mtime 早于源码即 FAIL）；
4. `tools/_m9_rebuild_stage.py --webview2-from dist/白板M22-物理仿真测试包.zip`
   （webview2 不可再生，从上一版完整包取回；本次 DEFAULT 已预指 M23 包）；
5. `tools/_m9_pack.py --variant both`（TESTCARD_EDITS 10 锚点预检全过才压）；
6. `artifacts/smoke_pkg.py` 双包冒烟（EXP_TOOLS 24/22、EXP_TILES 15/15、
   EXP_TARGETS 62/60、folded 9/7、插件 11/10——轻量版断言 `plugins/nativesim` 不存在）；
7. 收尾：`_m9_cleanup_dist.py --go`（KEEP 已换 M23 双包名）。
