 数理墨 · M26 测试包（数学键盘：函数输入 / 公式 LaTeX 共用一套键盘）

【这个包是什么】
  这一版（M23）围绕课堂工具体做了六件事：
    1. ★ 坐标系升级成一个族：「坐标系」瓦片右上角的小箭头里现在有三项 ——
       坐标系（带网格）、无网格（只画 xOy 两根轴）、空间坐标（xOyZ 三维轴测图）；
    2. ★ 新增「学科工具」瓦片：图片资料库，本版收录「电场线」六张教学插图
       （正/负点电荷、等量异种/同种、匀强电场、静电平衡导体），点图自动落到卷面；
    3. ★ 网页仿真修复：电路模拟器打不开 / 白屏这类"点了没反应"的故障，
       现在会**明确告诉你原因**（加载失败有提示、有日志），并且支持重试；
    4. ★ PhET 物理仿真扩齐：从 1 个增加到 45 个，按板块分组
       （力学 / 振动与波·声与光 / 电磁学 / 热学与流体 / 天体与近代），
       简体中文优先，没有简体的用繁体（仅 1 个），再没有的才英文；
    5. ★ 默认深色补丁：老版本把"出厂默认白纸"写进了偏好文件、导致升级后
       打开仍是白底的机器，本版启动时自动一次性迁回**深灰（黑板）**；
    6. 轻量版瘦身：物理仿真插件（含原生单摆/弹簧/斜面与网页仿真入口）
       只保留在完整版，轻量版不再带。
  上一版的物理仿真（M22）、界面美化（M20）与默认值调整（M21）原样都在，
  上课的操作方式一点没变，键盘快捷键也没变。

  本版（M24，含 M24 热修）在此之上修了三件课堂里的老大难：
    ★ 书写时偶发的「横贯直线」—— 手掌误触或红外框毛刺混进笔迹时，
      以前会连成一条长线，现在做了三层过滤（包内逐点检查、坏点丢弃、
      写回截断），直线没有画出来的机会；
    ★ 落笔那一下也不再漏检：以前只查「笔画中途」的手掌并入，落笔后立刻
      搭上手掌的那一跳没人管 —— 现在落笔点也登记成基准、落笔那一包里逐点查；
    ★ 手掌 / 多余触点不再画出杂笔：只认最先落下的那一触点写字，
      其它触点（手掌边沿、误碰）一律忽略；
    ★ 被丢弃的那一笔不再「复活」：以前按 Ctrl+Z 会把那条已经丢掉的长线
      重新变出来，还会白白吞掉一次撤销 —— 现在丢弃即彻底抹掉。

  本版（M25）在此之上，给参数面板加了「能改内容」的能力（以前只能改数值）：
    ★ 函数曲线选中后，参数面板里直接改表达式：把 a*x^2 改成 x^3、回车，
      曲线立刻重画，不用删了重画；参数字母的取值、三个标注开关也都能在面板上改；
    ★ 公式（LaTeX）选中后，参数面板里直接改 LaTeX 原文（多行输入），点「应用」
      卷面上的公式就更新；改错了会显示虚线占位框并提示无效，不会白屏；
    ★ 以上改动都进撤销栈：Ctrl+Z 一步退回原式（与 M24 的「撤销对得上账」同源）。

   本版（M26）在此之上，把「数学键盘」统一成全程序同一份实现（两处输入窗共用）：
     ★ 函数输入窗的键盘**键位与上一版逐键一致**（sin( / cos( / √( / ^ / π、数字、
       小键盘、方向键都在）—— 你熟悉的敲法一点没变；
     ★ 点「公式」瓦片打开的公式面板里，现在有整套 **LaTeX 数学键盘**：第一行是
       结构骨架（a/b 分式、√、^、∑、∫、lim…），还有关系符号、希腊字母、常用函数；
       按「a/b」这类**骨架键**，光标自动落进花括号里，接着打字就是分子 / 被开方数，
       不用自己敲反斜杠和花括号；
     ★ 两个输入窗的编辑手感统一：按「{」自动配对成 {}（光标停在括号**里面**，
       续打的字落在括号内）、左移 / 右移 / 退格 / 清空都可用。

  ★ 坐标系族怎么用（本版重点）：
    · 点「坐标系」瓦片（或按键盘 **C**）= 带网格的平面直角坐标系（跟以前一样）；
    · 点它右上角的**小箭头**：「无网格」= 只画 xOy 两根轴与刻度数字，
      适合在卷面上自己标坐标；「空间坐标」= 三条轴的立体图
      （x 轴指向左下 45°、y 轴水平向右、z 轴竖直向上），适合讲空间向量与投影；
    · 三种的按法相同：按下放原点（自动吸页中心/页边），拖出单位长度，抬笔落下；
    · 落下后都能用「选择」拖动 / 旋转 / 缩放，选中还能在参数面板改范围与步长。

  ★ 学科工具（电场线）怎么用：
    · 点「学科工具」瓦片 → 弹出图片资料库（左侧分类：电场线，右侧缩略图）；
    · 点任意一张图 → 自动落到**卷面中央**，拖动 / 缩放到题目旁边即可；
    · 可连续放多张；图片跟工程一起保存，Ctrl+Z 一步撤销；
    · 以后加新分类（如磁场线、光路图）会直接出现在左侧列表里。

  ★ 网页仿真（本版重点修复）：
    · 仿真窗右下「电路」组进电路模拟器；「力学」等五个板块下是 PhET 仿真
      （共 45 个，按板块分组，第一次打开某个仿真要等两三秒）；
    · ★ 加载失败不再装死：资源缺失或加载超时（30 秒），屏幕上会明确写原因，
      状态栏与日志里也有 —— 再点一次就是重试；
    · 电路模拟器仍是**英文界面**（官方包原样）；PhET 里 44 个是简体中文、
      1 个是繁体中文，没有重复。

  · 本包自带 WebView2 运行时与 GeoGebra / 物理仿真离线资源，目标机【不需联网、
    不需安装任何东西】—— 解压、双击、就能用。
  · M7.5 / M8 / M9 / M10 / M11 / M12 的功能一个都不少（F9 仍可切换工具栏显隐）。
  · M13~M22 的全部功能（悬浮球 / 纸张底色 / 计算器 / 公式 / 电路自动连线 /
    工具栏方形排列 / 三角板沿边画线 / 断笔直线修复 / 笔迹平滑 / 圆规与圆弧 /
    物理仿真）都在，只是按钮换了位置、换了长相。


【怎么运行】
  1. 把整个 zip 解压到任意文件夹（别只解压单个文件出来）；
  2. 双击 MathPhys.Ink.exe；
  3. 杀毒软件/SmartScreen 拦截就选「仍要运行」（本程序无安装器、无网络行为）。


【包很大是正常的】
  GeoGebra 离线资源 + PhET / 电路离线包 + WebView2 运行时加起来约 1.1 GB
  —— 这是「免安装、断网可用」的代价。

────────────────────────────────────────────────────────────
 已知的几件小事（不用测，先说明，免得当成坏了）
────────────────────────────────────────────────────────────
 · ★ 深色迁移只做**一次**：如果你以前手动选过「白」，这次升级后会被重置成
   深灰 —— 这是故意的（旧版本把默认值误当成了你的选择）。想用白底，
   「更多 → 纸张底色」点一下就是，之后不会再被自动改；
 · 「无网格 / 空间坐标」折叠在「坐标系」瓦片的小箭头里：被折进去的工具
   **一个都没删**，只是从"占一格"改成"点小箭头才露出来"；
 · 「空间坐标」是**静态轴测图**（x 轴固定指向左下 45°），不是能旋转的三维场景
   —— 课堂用法是给一副标准空间坐标系，在上面标点、画向量、讲投影；
 · 「学科工具」里的图落上卷面后是**图片**（与物理仿真导出同款），
   可拖动缩放、随工程保存，但不是矢量重画 —— 放大到特别大会有轻微模糊；
 · ★ 网页仿真是**完整版才有**；本版起**轻量版连「物理仿真」瓦片都没有**
   （整个插件只保留在完整版）—— 轻量版这不是坏了，是瘦身了；
 · ★ 双击 exe 后弹「文件不完整」或启动即闪退：不是程序坏了 —— 是压缩包
   还没解压完就双击了，或者直接在压缩包里双击了。把压缩包【完整解压】
   到一个文件夹再运行；本版起遇到这种情况会弹一句中文指引，不再闪天书报错；
 · PhET 的 45 个仿真第一次打开要等两三秒（加载官方离线包）；
   「电路组装套件：交流 / 直流」体积最大，第一次开要等四五秒；
 · 电路模拟器是**英文界面**（官方包原样）；PhET 里 44 个简体中文、
   1 个繁体中文（傅里叶：造波），没有重复；
 · 公式面板**不支持中文**（上游能力边界）；
 · 把 .twb 拖到白板上还**不会**打开它（拖拽未做），请双击文件或用「打开工程」；
 · ★ 墨色有 **6 颗**色块（末尾那颗是白）。深灰纸上用「白」——
   黑笔在深灰底上看不见，那是颜色问题不是故障；
